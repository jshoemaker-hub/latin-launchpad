# Seek & Find artwork

These ten original scene illustrations were generated for Latin Launchpad with the built-in OpenAI image-generation tool. The website uses the compressed JPEG files in this directory; source PNGs remain in Codex's generated-image archive.

## Final prompt set

Every scene used this shared direction:

> Create a richly detailed, responsive 3:2 picture-search scene for elementary and middle school Latin students. Use a polished original children's editorial illustration style with hand-painted gouache and colored-pencil texture, crisp shapes, warm expressive characters, and inviting educational puzzle art. Distribute the six target objects across separate regions so each remains recognizable at small website sizes. Keep the ancient Roman setting historically plausible and age-appropriate. No text, letters, labels, logos, watermark, borders, photorealism, modern objects, danger, or confusing duplicates of target objects.

Scene-specific prompts added these settings and targets:

| File | Setting | Six target objects |
| --- | --- | --- |
| `forum-market.jpg` | Roman Forum marketplace | temple/forum, stone road, market shop, bread, coin, grapes |
| `garden-dog.jpg` | Roman villa garden | dog, tree, stone table, cat, rose, feather |
| `roman-baths.jpg` | Roman bathhouse | pool water, doorway, column, oil bottle, strigil, bench |
| `roman-dinner.jpg` | Roman dining room | bread, olives, cup, table, lamp, amphora |
| `farmer-wolf.jpg` | Roman farm at twilight | farmer, dog, sheep, villa, moon, shepherd's crook |
| `school.jpg` | Roman classroom | teacher, scroll book, wax tablet, stylus, lamp, satchel |
| `river-boat.jpg` | Tiber River and dock | boy, ship, sail, oar, fish, rope |
| `romulus-remus.jpg` | Hills of early Rome | twin brothers, shepherd, wall, crown, hill, she-wolf |
| `harbor-trade.jpg` | Roman harbor | merchant, sailor, ship, amphora, pepper, anchor |
| `aeneas-troy.jpg` | Aeneas's journey to the ships | Aeneas, father, son, ship, shield, travel bundle |

The first Forum image established the style reference. Each later generation used it only as a visual-style reference while creating a completely new scene.
